## 1. 背景与目标

用户需要一个运行在 macOS 上的本地音频播放器，专注于播放本地 MP3 文件。市面上主流播放器要么绑定在线曲库、要么功能臃肿，缺少一个"打开即播、键盘友好、没有多余功能"的轻量工具。

**产品目标：**

1. 简洁：界面只保留常用操作，学习成本为零。
2. 键盘友好：所有高频操作（播放/暂停、快进快退、音量、切歌）都有快捷键。
3. 本地优先：播放只依赖本地文件，无账号、无打扰；网络能力仅限用户自带密钥、显式启用的可选转录功能（v1.1）。

**成功标准（v1.0）：**

- 可以替代作者本人日常播放本地 MP3 的现有工具。
- 冷启动到开始播放 < 3 秒。
- 所有高频操作均可仅靠键盘完成。

## 2. 目标用户与场景

**目标用户：** 在 macOS 上需要播放本地 MP3 文件的个人用户（音乐、播客、有声书）。

**典型场景：**

- S1：把若干 MP3 拖进窗口，顺序连续播放，边工作边听。
- S2：听播客/有声书时，用 ←/→ 精确回退/快进若干秒，无需碰鼠标。
- S3：中途退出应用，下次打开时从上次的位置继续播放。
- S4：使用耳机线控或键盘上的媒体键控制播放，不需要切换窗口。
- S5：听英文播客/有声书时，右侧自动出现与播放进度同步的文稿，边听边看，点击句子即可回跳。（v1.1）

## 3. 产品范围

### 3.1 v1.0 包含

| 模块 | 说明 |
| --- | --- |
| 播放核心 | 播放/暂停、进度跳转、音量、静音、播放速度 |
| 播放列表 | 添加/删除/清空、点击切歌、上一首/下一首、循环模式 |
| 快捷键 | 完整的键盘快捷键体系（见 §6） |
| 自定义步长 | 快进/快退步长可在设置中以秒为单位修改 |
| 文件接入 | 打开文件对话框（⌘O）、拖拽文件进窗口 |
| 状态记忆 | 退出时记住播放列表、进度、音量等，下次启动恢复 |
| 媒体键 | 响应系统媒体键，接入 macOS「正在播放」 |

### 3.2 明确不做（非目标）

- 在线/流媒体音乐、账号体系。
- 歌词显示、均衡器、音效、音频标签编辑。
- MP3 以外的格式（AAC/FLAC/WAV/OGG 等，留待后续版本）。
- Windows / Linux 支持。
- 曲库管理（文件夹扫描、搜索、分类）。

> 注：转录文稿（语音转文字，v1.1 规划）面向播客/有声书，与「歌词显示」不同，不在排除范围内。

### 3.3 v1.1 包含（规划中）

| 模块 | 说明 |
| --- | --- |
| 转录文稿 | 播放时自动调用云端 ASR（Deepgram，用户自带密钥）生成文稿，随播放进度滚动高亮，支持点击跳转；结果本地缓存 |

## 4. 功能需求

### 4.1 播放核心

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| FR-01 | 播放 / 暂停 | 单一按钮切换；暂停时保留进度 |
| FR-02 | 进度控制 | 进度条显示当前位置/总时长（格式 `mm:ss`），支持拖拽和点击跳转 |
| FR-03 | 快进 / 快退 | 按当前设置步长（默认 5 秒）前进/后退，不越界（<0 取 0，>总时长取总时长） |
| FR-04 | 音量 | 0–100%，滑块 + ↑/↓ 快捷键（步长 5%） |
| FR-05 | 静音 | 一键静音/取消静音，静音状态有明确视觉标识，取消后恢复原音量 |
| FR-06 | 播放速度 | 0.5x / 0.75x / 1.0x / 1.25x / 1.5x / 2.0x 档位切换，默认 1.0x |
| FR-07 | 播放结束行为 | 由循环模式决定（见 FR-11） |
| FR-08 | 出错处理 | 文件损坏/无法解码时提示错误，自动跳到下一首 |

### 4.2 播放列表

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| FR-09 | 添加 | 两种方式：⌘O 打开文件对话框（可多选）；拖拽文件进窗口 |
| FR-10 | 列表操作 | 单击条目开始播放；支持删除选中条目、清空列表；当前播放曲目高亮 |
| FR-11 | 循环模式 | 三档循环切换：**列表循环**（默认）→ 单曲循环 → 顺序播放（播完最后一首停止） |
| FR-12 | 条目展示 | 显示文件名（不含扩展名）与时长；时长可异步加载 |
| FR-13 | 去重 | 同一文件路径重复添加时忽略并提示 |
| FR-14 | 格式过滤 | 仅接受 `.mp3` 文件；其他文件被添加时忽略并给出轻提示 |
| FR-15 | 空状态 | 列表为空时显示引导文案（如「拖入 MP3 或按 ⌘O 打开」） |

### 4.3 自定义步长（设置）

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| FR-16 | 步长设置 | 快进/快退步长，单位秒，范围 1–120，默认 **5 秒** |
| FR-17 | 设置入口 | 菜单栏「设置…」（快捷键 ⌘,），以弹窗形式呈现 |
| FR-18 | 设置持久化 | 修改立即生效并持久保存 |

> 音量步长 v1.0 固定为 5%，不开放设置。

### 4.4 状态记忆

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| FR-19 | 记忆内容 | 播放列表（文件路径）、当前曲目、播放进度、音量、静音状态、播放速度、循环模式 |
| FR-20 | 恢复 | 下次启动自动恢复；若上次正在播放，恢复后保持暂停态，由用户手动按空格继续 |
| FR-21 | 失效处理 | 恢复时若文件已不存在/被移动，跳过该条并在列表中移除，轻提示用户 |
| FR-22 | 崩溃保护 | 播放过程中定期（约每 5 秒）落盘进度，异常退出也能大致恢复 |

### 4.5 媒体键与系统集成

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| FR-23 | 媒体键 | 键盘/耳机上的播放暂停、上一曲、下一曲媒体键可控制应用，应用失焦时也有效 |
| FR-24 | 正在播放 | 接入 macOS「正在播放」（控制中心/锁屏可见），显示当前曲目标题 |

### 4.6 转录文稿（v1.1，规划中）

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| FR-25 | 自动转录 | 开始播放（含自动切歌）即自动请求转录；文稿返回前面板显示「正在转录中…」；转录不阻塞播放 |
| FR-26 | 文稿面板 | 右侧面板按句子展示当前曲目的文稿；无曲目、未配置密钥、转录中、出错各有对应状态 |
| FR-27 | 同步滚动与高亮 | 播放中高亮当前句子并自动滚动到可见区域 |
| FR-28 | 点击跳转 | 点击文稿中的任意句子，播放跳转到该句起始时间 |
| FR-29 | 转录缓存 | 按「文件路径 + 大小 + 修改时间」缓存结果，重复播放不再请求、零费用；面板提供「重新转录」 |
| FR-30 | 密钥管理 | 设置中填写/替换/清除自己的 Deepgram API 密钥，加密保存；未配置时给出引导，不阻塞播放 |
| FR-31 | 错误与降级 | 密钥无效、额度不足、网络失败时以面板/Toast 提示，播放不受影响；转录出错可一键重试；v1.1 仅面向英文内容 |

## 5. 界面与交互

### 5.1 窗口形态

- 标准 macOS 应用窗口，Dock 显示图标，支持系统深色/浅色外观。
- 单窗口，固定最小尺寸（v1.0 为 480×360；v1.1 左右分栏后提高，见 §5.4），可自由拉大。

### 5.2 布局草图

```
┌────────────────────────────────────────┐
│  ● ● ●   myPlayer                      │  ← 标题栏
├────────────────────────────────────────┤
│  [+] [−] [清空]                        │  ← 工具栏：添加 / 删除 / 清空列表
├────────────────────────────────────────┤
│                                        │
│   1. 歌曲名 A                 03:24    │
│ ▶  2. 歌曲名 B（当前播放）     04:12    │  ← 播放列表
│    3. 歌曲名 C                 02:58    │
│                                        │
├────────────────────────────────────────┤
│  01:23 ▬▬▬▬▬●▬▬▬▬▬▬▬▬ 04:12           │  ← 进度条
```

### 5.3 反馈与提示

- 轻量 Toast 提示（自动消失）用于：添加了不支持的文件、重复添加、文件失效移除等。
- 播放错误使用明显的错误提示（条目级标红或 Toast）。

## 6. 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `空格` | 播放 / 暂停 |
| `←` / `→` | 快退 / 快进（步长 = 设置值，默认 5 秒） |
| `↑` / `↓` | 音量 +5% / −5% |
| `⌘←` / `⌘→` | 上一首 / 下一首 |
| `M` | 静音开关 |
| `L` | 切换循环模式（列表循环 → 单曲循环 → 顺序播放） |
| `⌘O` | 打开文件添加到列表 |
| `⌘,` | 打开设置 |

**规则：**

- 焦点位于输入框（如设置中的步长输入框）时，单字符快捷键（空格、M、L）不生效，避免误触。
- 快捷键在 v1.0 不可自定义，自定义快捷键留待后续版本。

## 7. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 性能 | 冷启动 < 2 秒（Apple Silicon）；快进快退响应 < 100ms；日常播放内存占用 < 300MB |
| 兼容性 | macOS 12 Monterey 及以上；同时支持 Apple Silicon 与 Intel |
| 隐私 | 播放路径纯本地，不采集任何数据；唯一网络功能为 v1.1 转录：仅在用户配置密钥并播放时，把音频发送给用户自选的 Deepgram 服务 |
| 语言 | v1.0 仅简体中文 |
| 可靠性 | 异常退出不丢失播放列表；进度恢复误差 ≤ 5 秒 |
